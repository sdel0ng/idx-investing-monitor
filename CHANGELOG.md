# Changelog

## v1.0.0 – 2026-11-23
First public release.
- Desktop app: Home, Portfolio, Screener, Heatmap, Macro, Ideas, Dividends, Reports, Journal, Alerts, Settings.
- Stock page with live chart, TA overlay (swings, S/R, trendlines, double bottom/top, Fibonacci, RSI divergence) and trade ticket.
- Queue plans with exits, targets, breakout trigger and macro rules (gold / IHSG / USD-IDR).
- Price alerts and index flow watch (MSCI rebalance selling-pressure monitor).
- Journal handles trades with unknown lot size (% result only).
- Phone mode (PWA, PIN, off by default) and Android APK built by GitHub Actions.
- Version shown in the page footer.
